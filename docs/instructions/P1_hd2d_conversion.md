# 지시문 P1 — HD-2D 전환 프로토타입

> 발행: HQ 세션 / 2026-08-21
> 참조: `fallingdown_game_design.md` **v2.0** (필독 — 특히 4장 뷰/레이어, 10.0 동선, 17장 검증 항목, 부록 A), `docs/00_development_plan.md` v1.0, `docs/reports/M1_report.md`·`M1_review.md`
> 수행: 개발 파트 세션. 범위 외 작업 금지. 기획서 대비 편차·미정값은 전수 보고 (M1 리포트 방식).

## 목적

M1(3D 그레이박스)은 실기기 검증에서 "3D 베이스로는 밸런스 확보 곤란" 판정을 받았다. 검증된 코어 로직을 이월해 **뷰·판정을 HD-2D 다운 스크롤로 전환**하고, 기획서 v2 17장 검증 항목을 실측한다. 사용자가 "2D 베이스로 밸런스를 잡을 수 있겠다"를 판정하는 것이 이 마일스톤의 게이트다.

## 착수 절차

1. 브랜치: 최신 `origin/main`에서 `claude/p1-hd2d` 생성. main에 `game/`이 없으면 `origin/claude/m1-graybox`를 먼저 머지해 M1 코드를 확보한다 (HQ가 사전 머지했는지 확인).
2. **재사용 (수정 최소화):** `src/core/` 전부 — 입력 분류기(✅오분류 0%), 속도 다이얼, 게이지, 웨이브 러너, 생애주기 규칙, balance 데이터 모듈, RNG. Playwright 테스트 체계.
3. **교체:** 렌더러(3D 원근 씬 → HD-2D 레이어 합성), 판정 투영(원근 투영 → 2D 평면 좌표), 적 동선(소실점 접근 → 하단 진입·상방 통과).

## 구현 범위

### 1. HD-2D 레이어 씬 (기획서 v2 4장)

- 고정 카메라. 소녀 스프라이트(플레이스홀더: 2등신 비율의 단색 실루엣 — 측면 뷰, 접음/펼침 2포즈) 화면 세로 40~45%·가로 중앙.
- 레이어: ① 스카이 그라데이션+구체 ② 패럴랙스 구름 2~3장 ③ **3D 오브젝트 레이어** (로우폴리 프리미티브 유적 2~3종이 스크롤에 따라 깊이감 있게 통과 — HD-2D 성립 검증용 최소 구현) ④ 게임플레이 2D 평면 ⑤ 전경 속도선·파티클.
- 속도 표현: 스크롤 속도 비례 + 카메라 미세 줌(1.0→1.06) + 셰이크. 낙하 속도 다이얼 수치는 M1 그대로.

### 2. 2D 판정 (기획서 v2 5장·10.0장) — r2 개정: 판정 영역 A/B

- **판정 영역 2방식을 모두 구현하고 튜닝 패널 토글로 전환 가능하게 한다** (2026-08-27 사용자 결정 — 실기기 실측으로 확정):
  - **A. 원형 링:** 소녀 중심 2D 원 (반경: 화면 폭 대비 초기 60~70%, 패널 조정)
  - **B. 화면 밴드:** 소녀 높이의 가로 발광 밴드 (높이 = 초기값을 원 지름과 등가로, 패널 조정). AD 권고안 — 적이 밴드로 진입하는 순간이 1프레임에 읽히는 타이밍 축
  - 두 방식 모두: 진입 하이라이트 + 비프음 큐, 진입 시 체류 시간 규칙 동일 적용. 판정 로직은 전략 패턴으로 격리해 전환 비용 최소화.
  - 리포트에 A/B 비교 실측 포함: 방식별 히트 성공률(오토플레이+합성 입력), 좌우 진입 적 대응 차이, 시각 혼잡도 소견.
- 적 동선: 통과형 = 하단·사선 하단 진입 → 상방 이동 → 링 스침 → 상단 프레임 아웃. 체류형 = 링 주변 선회 (선회 반경·배치각을 패널에 노출 — 혼잡도 검증 항목 5의 손잡이). 링 체류 시간·공격 주기 표는 v2 7장 그대로.
- 스와이프 판정: 화면 좌표 선분 vs 링 내 적 스프라이트 원형 히트박스 교차. 우산/검 궤적 폭·재판정 간격은 M1 잠정치 이월.
- a-1~a-5 + 도약 + HP + 콤보 + 웨이브 시퀀스: M1 규칙·데이터 이월 (a-6·B계열·보스는 범위 외 유지).

### 3. 베기 궤적 이펙트 (본 개편의 액션 아이덴티티 — 유일한 연출 투자 허용 항목)

- 스와이프 시 화면을 가로지르는 과장된 절단 궤적 (기획서 v2 부록 A-2 참조: 폭이 크고 잔광이 남는 흰 궤적). 우산(넓은 호)/검(가늘고 예리)의 시각 차별화. 히트스톱 40ms + 격파 파편.
- 셰이더/프로시저럴 구현 우선 (텍스처 에셋 금지 원칙 유지).

### 4. 게이지 배율 A/B (기획서 v2 7장 미결 항목)

- 튜닝 패널에 **게이지 배율 적용 ON/OFF 토글**을 두고, 양쪽 모두 자동 실측(게이지 100% 도달 시각, 판당 도약 횟수)을 리포트에 기록. 기본값 OFF(HQ 권장안).

### 5. 튜닝 패널·통계 (M1 이월 + 확장)

- M1 패널 항목 유지 + 추가: 링 반경(화면 폭 %), 선회 반경·배치각, 스크롤 속도 계수, 줌·셰이크 강도, 게이지 배율 토글, 3D 오브젝트 밀도.
- 통계: FPS/1% low/draw call, 오버드로우 추정치(레이어 수), 입력 분류 카운트.

### 6. 픽셀 스케일링 정책 검증 (기획서 v2 17장 7)

- 저해상도 렌더타깃 → 정수 배 업스케일 방식과 네이티브 해상도 방식을 토글로 비교 가능하게 구현 (AD 스타일 확정 전 기술 검증).

## 자가 검증

- 최초 병렬 실행 플레이크(M1 검수 지적) 대기 조건 보강.
