# 지시문 P1.5 — 픽셀 목업 (아트 적용 플레이어블)

> 발행: HQ 세션 / 2026-08-27
> 목적: P1 플레이어블에 **실제 픽셀 아트와 팔레트 통일 이펙트를 적용한 목업**을 만든다. 사용자가 "픽셀 아트·이펙트가 적용된 화면"을 보고 P2 전면 진입과 스토리 디벨롭 방향을 판단하기 위한 중간 스프린트다. P2의 아트 통합 일부를 앞당기는 것으로, 완성도보다 **분위기 성립 확인**이 목적이다.
> 수행: AD 세션(§A) + 개발 세션(§B) 병행, HQ 통합·배포.

## 범위 (전체)

- 대상 화면: 현 P1 90초 시퀀스 그대로. 신규 시스템 없음.
- 픽셀화 대상: 소녀(2스탠스), a-1, a-3(편대), 배경 1종(챕터1 톤), HUD 스킨은 **범위 외** (현 HUD 유지).
- 이펙트: 신규 제작 없음 — 기존 프로시저럴 이펙트의 **색·질감을 확정 팔레트로 재조율** (니어블랙·딥인디고·콜드시안·바이올렛 + 시안/마젠타 액센트, 마젠타는 소녀 전용).

## §A. AD 세션 작업

1. **선행: 캐릭터 시트 v1r2(엄격 2등신 보정) 완료 + 사용자 승인** (진행 중인 재생성 건).
2. 승인된 시트를 소스로 **Sprite-Gen 파이프라인을 실행해 게임 반입용 스프라이트 시트 산출**:
   - 소녀: 측면 낙하 기본 2스탠스(접음/펼침) — P1.5에서는 **스탠스당 정지 1프레임 + 미세 흔들림 2프레임 이내** (애니메이션 본격화는 P2)
   - a-1: 비행 1~2프레임 / a-3: a-1 변형(소형·편대용)
   - 규격: 48×48(소녀), 적은 화면 비례 맞춤. 32~48색 공유 팔레트, 알파 배경, 아웃라인 없음
   - 산출: `art/sprites/` 아래 **시트 PNG + manifest.json** (Sprite-Gen 출력 그대로) — 이 형식이 개발 반입 규격이다
   - 참고: 이미지 생성이 권한 대기로 막히면 **기존 커밋된 컨셉 PNG를 Sprite-Gen 외부 반입 경로로 사용**하는 대안 허용 (품질 미달 시 보고)
3. 배경 1종: 챕터1 톤(콜드시안·인디고)의 스카이 그라데이션 색상값 + 구름 레이어용 픽셀 텍스처 1~2장 (또는 프로시저럴 지시서 — 색상값·밴딩 단수만 문서로 줘도 개발이 구현 가능)
4. **이펙트 컬러 스펙 1페이지** (`docs/art/fx_palette_p15.md`): 베기 궤적(우산/검), 격파 플래시·파편, 밴드 라인, 하이라이트 점등색(민트 → 명도 기반으로 교체: P1 검수 지적 반영), 속도선 — 각각 hex 값과 강도 지침.

## §B. 개발 세션 작업

1. **스프라이트 반입 체계 (즉시 착수 가능):** Sprite-Gen `manifest.json` + 시트 PNG 로더 구현. 로더는 `art/sprites/`를 스캔해 실루엣 플레이스홀더를 자동 대체(시트 없으면 현 실루엣 유지 — 점진 적용 가능 구조).
2. 픽셀 스케일링 기본 ON (정수 배율, 현 구현 활용). 스프라이트는 `image-rendering: pixelated` 질감 유지.
3. §A-4 이펙트 컬러 스펙 적용: 기존 주스 패스 이펙트의 색만 교체 (파라미터화되어 있으므로 데이터 수정 수준). 하이라이트는 색상 대신 **명도 점프 + 외곽 발광**으로 변경.
4. §A-3 배경 적용 (색상값 기반 프로시저럴 우선, 텍스처 오면 교체).
5. 용량 보고: 스프라이트·텍스처 반입 후 빌드 크기 실측 (P1.5는 에셋이 처음 실리는 시점).

## 순서·게이트

1. DEV §B-1~2 선행 착수 (에셋 무관) → 2. AD 시트 승인 → 3. AD 스프라이트·스펙 산출 → 4. DEV 통합 → 5. HQ 검수·아티팩트 재배포 → 6. **사용자 목업 판정** (통과 시 SD 인터뷰 개시 + P2 본격 착수).
