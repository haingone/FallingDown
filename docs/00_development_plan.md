# FallingDown 개발 계획서

> 버전 1.0 (HD-2D 전면 개편판) / 2026-08-21
> 입력 문서: `fallingdown_game_design.md` **v2.0** (HD-2D 다운 스크롤 개편)
> v0.2 계획(3D 기반)은 M1 그레이박스 실기기 검증에서 "3D 베이스로는 밸런스 확보 곤란" 판정에 따라 본 판으로 대체한다. 본 문서는 HQ(프로듀서) 세션이 작성하는 전체 작업 계획이며, 실제 제작은 파트별 세션이 HQ 발행 지시문(`docs/instructions/`)으로 수행하고 HQ가 검수한다.

### 1.1 Git 운영 규칙

- `main` = 검수 통과분만. 세션별 브랜치 `claude/<작업명>`. 새 세션은 항상 최신 `main`에서 분기.
- **각 세션 작업 종료 시 HQ가 브랜치 처리 권장안(PR/머지/폐기)을 사용자에게 보고, 승인 후 실행.**

## 2. 기술 스택 (확정 유지 + HD-2D 확장)

**TypeScript + Vite + three.js + 앱인토스 WebView SDK** — v0.2에서 확정한 스택을 유지한다 (2026-08-21 재확인).

- HD-2D 구현 방식: three.js 씬에 **2D 스프라이트(게임플레이 레이어) + 로우폴리 3D 오브젝트(배경 레이어) + 패럴랙스 구름 레이어**를 혼합. 판정은 전부 2D 평면에서 수행 — 3D는 순수 연출 레이어라 밸런스에 영향 없음.
- **M1 자산 이월:** 로직-렌더링 분리 덕분에 `src/core/`(입력 분류기 ✅오분류 0%, 속도 다이얼, 게이지, 웨이브 러너, 생애주기 규칙)는 그대로 재사용한다. 교체 대상은 렌더러(3D 원근 → HD-2D 레이어)와 판정 투영(화면 공간 원근 → 2D 평면)뿐이다. Playwright 자가 검증 체계도 이월.
- 픽셀 아트 채택 시(AD 결정 대기): 정수 스케일링 + 렌더타깃 저해상도 렌더 후 업스케일 방식 검토 (P1 검증 항목).

## 3. 마일스톤 로드맵 (개편판 — P 시리즈)

게이트(검수 통과 조건)로 관리. 종료 시 HQ 검수 → 사용자 리뷰 → 브랜치 권장안 → 다음 지시문.

### P1 — HD-2D 전환 프로토타입 (지시문: `docs/instructions/P1_hd2d_conversion.md`)

M1 코어 로직을 이월해 뷰·판정을 2D로 전환하고, 기획서 v2 17장 검증 항목을 실측한다. 그레이박스 품질(플레이스홀더 스프라이트)로 진행하되 **"화면을 가로지르는 베기 궤적" 이펙트만은 프로토타입 수준으로 구현**한다 (본 개편의 액션 아이덴티티 검증이 목적이므로).

- 게이트: 폰에서 플레이 가능한 URL + 튜닝 리포트 (링 타이밍 가독성, 3.0x 가독성, 게이지 배율 A/B 실측, 혼잡도, HD-2D 성능) + **사용자 플레이 판정: "2D 베이스로 밸런스를 잡을 수 있겠다"**

### P2 — 버티컬 슬라이스

AD 확정 스타일·SD 확정 스크립트로 튜토리얼 + 챕터1 스테이지1을 최종 품질로.

- 선행 조건: P1 게이트, AD 스타일 확정 + P2 최소 에셋(소녀·a-1·a-3 스프라이트, 배경 1종, HUD 스킨), SD 튜토리얼 스크립트·캐릭터 확정
- 게이트: 기획서 16장 6감각 중 1~4 체감, 용량 실측, 사용자 플레이 승인

### P3 — 콘텐츠 프로덕션

챕터 1~3 전체 (웨이브 데이터는 JSON 분리 유지), A/B계열 전 타입, 보스, 성장 시스템, 미션, 컷씬. 수익화 설계(광고+IAP) 문서 병행 확정.

### P4 — 플랫폼 연동·출시

앱인토스 WebView SDK 연동, 최적화, 게임 정보 등록·심사 (계정 준비 완료 — 등록 단계부터).

## 4. 아트 파트 (AD) — 개편 반영

AD 지시서 개정판 기준. 고정 제약:

- **스타일 골격 (사용자 확정, 2026-08-21):** HD-2D — 2D 캐릭터·배경 + 일부 3D 오브젝트. **2등신 캐주얼·귀여운 캐릭터 + 스피디한 과장 이펙트**의 대비가 핵심 모티프. 컨셉 목업 3종(기획서 v2 부록 A)이 무드 기준점이며 프로덕션 디자인은 AD 탐색·사용자 승인으로 확정.
- P2 요구: 확정 스타일 + 소녀·a-1·a-3 스프라이트 시트 + 배경 1종 + HUD 스킨. 스프라이트 프레임 규격(용량 예산 2.1) 수립 포함.
- P3 요구: 전 적/보스, 전 UI, 챕터 배경 3종, 컷씬 일러스트. P4 요구: 스토어 비주얼.
- 실작업 분담(스프라이트 제작 도구·3D 오브젝트 제작 주체)은 AD가 마일스톤 수립 시 사용자와 협의해 확정.

## 5. 스토리 파트 (SD) — 개편 영향 없음

세계관 캐논(기획서 v2 3장) 유지 확정. SD 지시서·마일스톤·인터뷰 계획 그대로 진행. 캐릭터 확정본이 AD의 2등신 캐릭터 디자인 입력이 되는 의존성만 유의 (캐릭터 확정 최우선).

## 6. 사운드 파트 — 유지

AI 생성. P1은 합성 비프음, 본 사운드는 P2부터. AD 확정 무드 기반 디렉션 문서를 HQ가 작성.

## 7. 검수 기준 (HQ 공통)

1. 기획서 v2 정합성 — 임의 변경 반려, 튜닝 결과는 기획서 개정으로 반영 (M1 방식 유지: 미정값·편차 전수 보고)
2. 기획서 16장 6감각 / 11.2 난이도 4축 (스탯 인플레 금지)
3. 용량 예산 마일스톤별 실측
