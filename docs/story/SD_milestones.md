# SD 자체 마일스톤 (초안 v0.1)

> 작성: 스토리 디렉터(SD) 세션 / 2026-08-24
> 입력: `docs/instructions/SD_charter.md`, `fallingdown_game_design.md` v0.9.1, `docs/00_development_plan.md` v0.2
> 지위: HQ 제출용 초안. HQ 승인 전까지 변경 가능.

## 고정 제약 (개발 마일스톤과의 통합)

- **M2 (버티컬 슬라이스) 요구:** 튜토리얼 인트로 스크립트 확정본 + 소녀·까마귀 캐릭터 확정본 (AD 시각화 입력)
- **M3 (콘텐츠) 요구:** 스토리 바이블 확정, 챕터 1~3 컷씬 스크립트, 인게임 텍스트 전량
- **AD 동기화:** 캐릭터·세계관 확정이 AD 캐릭터 컨셉보다 선행 — 캐릭터 확정을 최우선으로
- **HQ 확정 결정 (개발 계획서 9장):** "전체 아크 확정 후 튜토리얼 상세 선행" — 바이블 아크가 튜토리얼 스크립트에 선행한다
- **캐논:** 기획서 3장 인트로 상황 + 3.1 조작 학습 매핑 변경 불가

| ID | 이름 | 산출물 | 완료 기준 (게이트) | 공급 대상 |

| SD-6 | 구현 검수 | 검수 리포트 (`docs/reports/`) | 인게임 텍스트·컷씬이 의도 부합 판정 | M3~M4 빌드 검수 |

## 순서·병행 원칙

```
SD-1 (인터뷰) ──> SD-2 (캐릭터) ──> [AD 착수 가능]
        └───────> SD-3 (바이블) ──> SD-4 (튜토리얼) ──> [M2 게이트]
                        └─────────> SD-5 (콘텐츠 전량) ──> [M3 게이트]
                                            └──> SD-6 (검수, 구현과 병행)
```

- SD-2와 SD-3은 같은 인터뷰 결과에서 출발하므로 부분 병행 가능하나, **AD 대기를 만들지 않기 위해 SD-2 완결을 우선**한다. 캐릭터의 정체(내력)는 바이블 소관이므로, SD-2 확정본은 "AD가 시각화에 필요한 범위(외형 지침이 되는 설정·성격·말투)"를 우선 확정하고 내력 상세는 SD-3에서 잠근다.
- 인터뷰는 마일스톤당 1~2회를 기본으로 하되, 사용자 반응에 따라 추가한다. 각 인터뷰는 3~5문항, 구체적 대안 제시형.

## 리스크

| 리스크 | 대응 |
|---|---|
| 인터뷰 왕복 지연으로 AD/M2 대기 발생 | SD-2를 최소 확정 범위(시각화 입력)로 좁혀 선행 통과 |
| 사용자 취향과 초안 방향의 재불일치 | 창작 후 통보 금지 — 매 단계 대안 2~3개 제시 후 선택받는 방식 유지 |
| 텍스트 예산 초과 (컷씬 30초, 대사 12자) | 집필 단계에서 글자 수 검산을 완료 기준에 포함 |
