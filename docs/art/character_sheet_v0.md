## AD 자체 검수

**성립한 것**

1. **까마귀 시트가 우수하다.** 6종이 색·액세서리로 명확히 구분되고, 최하단 소형 실루엣 검증까지 통과했다. 둥근 덩어리 실루엣이라 소녀와 혼동되지 않는다. **CS3는 이대로 확정 가능 수준.**
2. **소녀의 디자인 요소가 전부 명시됐다.** 턴어라운드 5방향 + 디테일 콜아웃 + 팔레트가 갖춰져 레퍼런스로 기능한다.
3. **표정 4종**(결의·놀람·미소·피격)이 소형에서도 구분된다.
4. **액션 프레임 시트**로 "몸은 귀엽게, 액션은 멋지게" 원칙이 프레임 단위로 정리됐다.
