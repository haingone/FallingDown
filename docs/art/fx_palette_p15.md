## 0. 전제 — 색이 아니라 명도로 구분한다

P1 검수 지적("하이라이트가 민트색으로 튄다")의 근본 원인은 **점등을 색상 이동으로 표현**한 것이다.
채도 높은 민트를 얹으면 팔레트 밖 색이 생기고 화면의 색 규율이 무너진다.

**교체 원칙: 점등 = 명도 점프 + 외곽 발광.** 색상은 그 요소의 기본 색을 유지하고 명도만 올린다.
민트(`#3EC2C1` 계열의 그린 성분)는 이펙트 하이라이트로 쓰지 않는다.

## 1. 역할별 색 예약 (충돌 방지)

| 색 | 예약 대상 | 금지 |
|---|---|---|
| **핫 마젠타** `#E60986` | **소녀 전용** — 의상 액센트, 피격 플래시 | 배경·적·UI·일반 이펙트에 사용 금지 |
| **콜드 시안** `#63DCE3` | **플레이어 액션 이펙트** — 베기 궤적, 파편, 잔상, 충격파 | — |
| **바이올렛** `#8A5CD8` | **적 액센트** (AFTERGLOW 포함, 마젠타에서 이관) | — |
| **화이트** `#FFFFFF` | 임팩트 코어, 최고 명도 프레임 | 넓은 면적 사용 금지 (1~2프레임 한정) |
| 니어블랙·딥인디고 | 실루엣·음영·배경 | — |

**주의 — 시안 3중 사용:** 시안이 ① 소녀 림라이트 ② 플레이어 베기 이펙트 ③ 적 눈 발광에 모두 쓰인다.
**명도로 분리한다:**

| 용도 | 명도(L) | 면적 |
|---|---|---|
| 플레이어 베기 이펙트 | **L 85~100** (`#63DCE3`~`#FFFFFF`) | 큼 (캐릭터의 2~4배) |
| 소녀 림라이트 | L 70~80 (`#3EC2C1`) | 1px 외곽선 |
| 적 눈 발광 | **L 55~65** (`#3C81A2`) | 2~4px 점 |

이펙트가 발생하는 순간 화면에서 가장 밝은 시안은 항상 플레이어 액션이다.

## 2. 요소별 스펙

### 2.1 베기 궤적 — 우산 (광역 호)

| 항목 | 값 |
|---|---|
| 코어 | `#FFFFFF`, 폭 2~3px |
| 바디 | `#63DCE3` → `#3C81A2` 그라데이션, 폭 6~10px |
| 형태 | **넓은 호(arc).** 스윕 각 120~160°, 반경 = 소녀 높이의 1.5~2배 |
| 지속 | 4프레임 (등장 1 · 유지 1 · 분해 2) |
| 분해 | 호가 3~6개 파편으로 끊어지며 소멸. 파편은 `#63DCE3`, 1~2px |
| 알파 | 100% → 0%, 마지막 2프레임에서 선형 |

### 2.2 베기 궤적 — 검 (가는 선)

| 항목 | 값 |
|---|---|
| 코어 | `#FFFFFF`, 폭 1px |
| 바디 | `#63DCE3`, 폭 2~3px |
| 형태 | **직선에 가까운 가는 궤적.** 3연격은 각도를 달리한 3개 선 |
| 지속 | 3프레임 |

**우산 vs 검의 구분은 색이 아니라 형태다** — 넓은 호 vs 가는 선. 스탠스 시인성의 핵심이므로 색으로 구분하지 않는다.

### 2.3 격파 플래시 · 파편

| 항목 | 값 |
|---|---|
| 플래시 | `#FFFFFF` 단색, **1프레임만.** 적 실루엣 전체를 흰색으로 치환 |
| 파편 | 적 본체 색(`#1D2C51`·`#23476C`)에서 채취, 4~8조각, 1~3px |
| 파편 하이라이트 | 파편의 20%만 `#3C81A2`로 (명도 점프) |
| 지속 | 플래시 1F → 파편 확산 5~8F |

### 2.4 밴드 라인 (판정 영역)

| 상태 | 색 | 강도 |
|---|---|---|
| 평상 | `#24274D` | 알파 35%, 1px |
| 적 진입 | `#3C81A2` | 알파 70%, 1px + 외곽 1px 발광 |
| 격파 순간 | `#63DCE3` | 알파 100%, 2px, 2프레임 후 평상 복귀 |

**색상을 바꾸지 않고 같은 시안 계열 안에서 명도·알파만 올린다.**

### 2.5 점등 하이라이트 (민트 교체)

민트 색상 → **명도 기반**으로 전면 교체:

```
점등 = 대상 색을 HSL 로 두고
       L += 25~35   (색상 H 고정, 채도 S 는 -10 이내로만 변화)
     + 외곽 1px 발광 (대상 색의 L +40, 알파 60%)
```

이 규칙은 적·UI·배경 오브젝트에 공통 적용된다. **어떤 요소도 점등 시 새 색상을 얻지 않는다.**

### 2.6 속도선

| 항목 | 값 |
|---|---|
| 색 | `#707DA2` (저속) → `#3C81A2` (고속). 채도가 아니라 명도로 속도를 표현 |
| 폭 | 1px 고정 |
| 밀도 | 속도 비례. 화면 가장자리에 집중, **중앙 40%는 항상 클린** |
| 알파 | 25~55%, 속도 비례 |
| 방향 | **세로(화면 아래→위).** 방사형 아님 — 정측면 Y축 낙하 뷰이므로 |

### 2.7 피격 (소녀)

| 항목 | 값 |
|---|---|
| 플래시 | `#E60986` (마젠타) 2프레임 |
| 사유 | 마젠타 예약의 유일한 예외. 캐릭터 위에서만·2프레임 이내이므로 예약 원칙과 충돌하지 않는다 |
