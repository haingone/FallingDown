# FallingDown 아트 디렉션 (A1)

> 버전 0.1 (초안 — 사용자 승인 게이트) / 2026-08-21
> 작성: HQ 세션 (아트 파트)
> 입력: 기획서 4장(로우폴리+툰 셰이딩, 세로 화면), 15장(HUD), 17.7(용량 100MB), 스토리 바이블 v0.1(고도별 세계)
> 첨부 컨셉 이미지: `art/concepts/` (본 문서와 함께 검토)

## 1. 스타일 정의

**"종이연극 같은 하늘" — 로우폴리 + 투톤 셰이딩 + 회화적 그라데이션 스카이돔.**

- 캐릭터·몬스터: 로우폴리 메시 + 툰 셰이딩(명부/암부 2단 램프 + 얇은 아웃라인). 텍스처는 플랫 컬러 위주로 최소화 (용량·성능 예산의 핵심).
- 배경: 지오메트리를 거의 쓰지 않는다. 회화적 그라데이션 스카이돔 + 로우폴리 구름·부유물 소수. 낙하 속도감은 배경 디테일이 아니라 파티클(속도선)과 FOV가 담당하므로 배경은 과감히 비운다.
- 실루엣 제일주의: 3.0x 최고속에서도 0.3초 안에 적을 식별해야 한다 (기획서 17.3). **모든 적은 색·형태만으로 1프레임 식별 가능해야 하며, 디테일보다 실루엣 차별화에 예산을 쓴다.**
- 금지: 사실적 라이팅, 노이즈 많은 텍스처, 화면 중앙을 가리는 연출 (기획서 15장 "중앙 무UI" 원칙의 아트 확장).

## 2. 컬러 스크립트 — 고도 = 시간 = 감정

낙하 진행(챕터)에 따라 하늘 전체의 팔레트가 바뀐다. 배경이 곧 진행도 표시이자 감정 곡선이다.

| 구간 | 팔레트 | 무드 | 스토리 대응 |
|---|---|---|---|
| 튜토리얼 (최상층) | 새벽 — 코발트블루 → 연보라, 지구는 차갑고 선명한 청록 | 경이, 낯섦 | "어디로 떨어지는가" |
| 챕터 1 (상층) | 한낮 → 노을 초입 — 하늘색 → 살구·금빛 구름바다 | 모험, 따뜻함 속 불안 | 잊힌 아이의 자각 |
| 챕터 2 (중층) | 노을 절정 — 주황·자홍·장미빛, 부유하는 잊힌 물건들의 역광 실루엣 | 애수, 계승 | 노파의 유산 |
| 챕터 3 (하층) | 박명 → 암흑 — 짙은 보라·남색, 움브라의 흑막, 광원은 소녀 주변뿐 | 긴장, 직면 | 움브라 근접 |

- 적·이펙트의 가독성 확보를 위해 **판정 링과 적 하이라이트 색(웜 옐로/시안 계열)은 전 챕터 공통 고정**하고, 배경 팔레트는 이 두 색과 충돌하지 않는 범위에서 설계한다.

## 3. 캐릭터 방향

| 대상 | 방향 |
|---|---|
| 소녀 | 10대 초반, 잠옷 위에 걸친 커다란 코트(병실→하늘의 서사 암시, 직접 묘사는 금지 원칙 유지). 머리카락·코트 자락이 낙하 바람에 위로 나부끼는 실루엣이 아이덴티티. 표정은 단순한 툰 페이스 (눈 크게, 입 작게) |
| 우산 | 낡고 클래식한 검은 장우산 + 은빛 첨단. 펼침 시 안감에 별자리 문양(노파의 흔적 — 챕터 2 복선). 손잡이에서 뽑는 검은 가늘고 발색이 밝은 은백색 (어두운 배경에서 궤적 가독성) |
| 까마귀 인형 | 헝겊 인형 티가 나는 둥근 실루엣 + 단추 눈 + 기운 자국. "살아있는 새"가 아니라 "날게 된 인형"임이 한눈에 보일 것. 손목에 매달리는 크기 |
| A계열 몬스터 | 조류형이되 "새"가 아니라 "새 모양으로 접힌 그림자"— 로우폴리 종이접기 느낌. 등급(하/중/상)은 크기와 색 온도로, 타입(a-1~6)은 실루엣으로 구분. **구체 디자인은 A2에서 코드명·패턴만 브리핑 받아 진행 (기획서 10장 선입견 금지 원칙)** |
| 지구 | 상층 하늘에 상시 떠 있는 거대한 청록 구체. 사실적 지구가 아니라 툰 처리된 "그리운 것"의 상징 — 멀어질수록(챕터 진행) 작고 뿌옇게 |

## 4. UI / HUD 방향

- 기조: 다이어제틱 우선, 순수 UI는 최소·반투명. 화면 중앙 무UI (기획서 15장).
- HP 5칸: 하트가 아닌 **깃털 5장** 아이콘 (세계관 자원과 통일). 상단 좌.
- 배율: 상단 우, 숫자 + 색 온도 변화 (1.0x 청색 → 3.0x 적색). 콤보 카운터는 그 옆 소형.
- 깃털 게이지 겸 도약 버튼: 하단 중앙, 까마귀 인형 실루엣이 게이지를 두르는 원형. 100% 시 발광·진동.
- 판정 링: 소녀 주변 얇은 원. 평상시 저채도, 적 진입 시 해당 적 외곽선과 함께 웜 옐로 하이라이트.
- 폰트: 손글씨 느낌의 라운드 산세리프 (한글 서브셋 필수 — 용량).

## 5. 이펙트 방향

- 베기: 흰 궤적 + 절단면 플래시 + 히트스톱. 우산(넓은 호) vs 검(가는 선)의 궤적 형태 차별화 = 스탠스 시인성의 핵심.
- 도약: 소녀 중심 방사형 충격파 + 배경 색 반전 플래시 1프레임 + 관통 경로의 깃털 흩날림.
- 속도선: 화면 가장자리 방사형 라인 파티클, 밀도는 속도 비례 (기획서 4장). 중앙부는 항상 클린하게.
- B계열 폭발: "위험(적 피해)"과 "전술(아군 광역)"이 같은 폭발이라도 색으로 구분 — 오폭발 = 탁한 자주, 규정 처치 폭발 = 밝은 금색.
