## 2. 이 확정이 기획서에 요구하는 개정 — **HQ 판단 필요**

2.5D + 정측면 전환은 아트 결정을 넘어 **프로덕트 정의를 바꾼다.** 아래는 현 기획서와 직접 충돌하는 항목이다.

| 기획서 | 현행 문언 | 충돌 내용 |
|---|---|---|
| **2장 셀링포인트 2** | **"Z축 3D 스와이프"** — 적이 소실점에서 카메라로 날아오고 판정 링에서만 벨 수 있다 | **셀링포인트가 성립하지 않는다.** 대체 셀링포인트 정의 필요 |
| 4장 | 3D 3인칭 추적 카메라, 로우폴리 + 툰 셰이딩, Z축 적 동선, FOV 60→72° | **전면 개정** — 2.5D 정측면 Y축으로 |
| 10.0 | 통과형: 원경 → 판정 링 통과 → 카메라 뒤 프레임 아웃 | 2D 동선으로 재정의 (아래에서 위로 상승 / 좌우 진입) |
| 15장 | "소녀 주변: 판정 링" | 2D 판정 영역으로 재정의 — **캐릭터 중심 원 / 화면 고정 중 미결** |
| 17.1 | 검증 항목 "판정 링 깊이 인지" | **삭제** — 깊이가 없어 검증 대상이 아님 |
| 17.7 | 용량 검증 전제 "로우폴리 3D + 툰 셰이딩" | 전제 변경 |

**AD 소견:** 셀링포인트 2번이 사라지는 것은 가볍지 않다. 다만 기획서 2장의 진짜 코어는 **셀링포인트 1번(낙하 속도 = 셀프 난이도 다이얼)** 이고, 이것은 정측면 Y축에서 100% 성립한다 — 오히려 낙하 속도가 배경 스크롤 속도로 직관적으로 보인다. 대체 셀링포인트는 **"2D 액션 손맛 + 속도 다이얼"** 축을 제안한다.

## 4. 해소된 리스크

2.5D 전환으로 다음이 **소멸**했다.

1. glTF 스킨 애니메이션 파이프라인 (계획서 8장 등재 리스크)
2. 3D 캐릭터 카메라·자세 성립 문제 — 본 세션 아트 탐색 5라운드를 소모시킨 원인
3. 캐릭터 메시·텍스처 용량 압박
4. 사용자 3D 제작 리드타임 (Blender/Tripo)
5. 픽셀 × Z축 원근 충돌 — 정측면 전환으로 애초에 발생하지 않음
