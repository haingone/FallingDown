> 입력: `docs/instructions/AD_charter.md`(5장 고정 제약), `docs/00_development_plan.md`(3·4장), `fallingdown_game_design.md` v0.9.1

## 0. 개발 마일스톤과의 정렬 개요

```
개발:   M1(그레이박스, 조건부 통과) ─ M2(버티컬 슬라이스) ─ M3(콘텐츠) ─ M4(출시)
AD:     AD-0 ── AD-1 ─────────────── AD-2 ─────────────── AD-3 ────── AD-4
        인터뷰   스타일 확정           M2용 에셋 디자인      M3용 전체     스토어 비주얼
```

- AD-1(스타일 확정)과 AD-2(M2용 디자인 시트)는 개발 M2의 **선행 조건**이므로 M2 착수 전에 완료한다.
- AD-3은 개발 M3 착수 전, AD-4는 M4 착수 전 완료를 목표로 한다.
- SD(스토리 디렉터) 의존성: 소녀·까마귀 **캐릭터 확정 컨셉**은 SD 확정본을 입력으로 한다. SD 미확정 구간에서는 스타일·무드 탐색(AD-1)까지만 진행 가능 — AD-2 착수가 SD-M2 산출물(캐릭터 확정)에 걸려 있다.

## AD-1 — 스타일 탐색·확정 (승인 게이트: 스타일)

인터뷰 결과를 반영해 **서로 구별되는 스타일 3안**을 제작하고 사용자와 수렴한다.

| 항목 | 내용 |
|---|---|
| 범위 | 3안 각각: 키 비주얼 1장 + 인게임 목업(세로 9:16, HUD 가배치 포함) 1장 + 스타일 정의 요약(렌더링 기법·팔레트·레퍼런스). 필요 시 2라운드(선택안 변주) |
| 제약 | 로우폴리 + MeshToonMaterial 툰 셰이딩으로 번역 가능한 스타일만 제안. 세로 화면·중앙 무UI·3.0x 가독성 전제 |
| 산출물 | `art/style/` 이미지, `docs/art/style_exploration.md`(3안 비교·선정 기록), 확정 시 `docs/art/art_direction_v1.md`(신규 아트 디렉션 — 반려본 대체) |
| 게이트 | **사용자 스타일 승인** (지시서 4.2). 컬러 스크립트(챕터별 팔레트) 방향 합의 포함 |
| 의존성 | 인터뷰 1회차 (SD 확정 불필요 — 무드·스타일 수준) |

## AD-2 — M2 대응: 캐릭터·최소 에셋 세트 (승인 게이트: 캐릭터)

개발 M2(버티컬 슬라이스)가 요구하는 전부를 공급한다.

| 항목 | 내용 |
|---|---|
| 범위 | ① 소녀(+우산 2스탠스·검)·까마귀 인형 확정 컨셉 — **SD 캐릭터 확정본 입력** ② a-1·a-3 적 컨셉 (코드명·등급·생애주기·패턴 정보만 사용, 실루엣 1프레임 식별 최우선) ③ 3D 제작용 에셋 디자인 시트 — 폴리 예산, 텍스처 규격(KTX2), 애니메이션 리스트, glTF 내보내기 규격 ④ 인게임 HUD 스킨 1세트 (치수·색상값·상태 정의 포함) ⑤ 이펙트 시각 언어 v1 (베기 궤적 우산/검 차별화, 히트, 링 하이라이트, 도약) |
| 산출물 | `art/characters/`, `art/enemies/`, `docs/art/asset_sheets/`(시트·스펙), `docs/art/ui_hud_v1.md` |
| 게이트 | 사용자 캐릭터 승인 + HQ 검수(용량 예산 정합: 메시 20MB·텍스처 20MB·UI 15MB 내 배분 계획) |
| 의존성 | AD-1 스타일 확정, SD 캐릭터 확정 (미확정 시 ②~⑤ 선행 진행 가능) |
| 검수 역할 | 사용자 3D 결과물(Blender/Tripo) 1차 검수 — 디렉션 부합·규격 준수 판정, 수정 지시 |

## AD-3 — M3 대응: 전 콘텐츠 그래픽

| 항목 | 내용 |
|---|---|
| 범위 | ① 전 적 컨셉: a-2·a-4·a-5·a-6, b-1~b-4, 중간 보스(mb)·챕터 보스(cb) 3종 — 등급은 크기·색 온도, 타입은 실루엣로 구분하는 체계 유지 ② 전 UI 킷: 메뉴, 스테이지 선택(적 조성 미리보기 포함), 성장 화면(우산/검/소켓/까마귀), 결과·미션 화면 ③ 챕터 1~3 배경(스카이돔·부유물) + 컬러 스크립트 확정판 ④ 컷씬 일러스트(SD 스크립트 기준, 정지 일러스트+연출 — 동영상 금지) ⑤ **에셋 마스터 리스트 v1** — 전 그래픽 에셋 목록 + 용량 예산 배분표 |
| 산출물 | `art/enemies/`, `art/backgrounds/`, `art/cutscenes/`, `docs/art/ui_kit.md`, `docs/art/asset_master_list.md` |
| 게이트 | 사용자 UI 킷 승인 + HQ 검수 (M2 용량 실측 반영한 예산 재배분 포함) |
| 의존성 | AD-2 완료, SD 스토리 바이블·컷씬 스크립트 확정 |

## 상시 임무 (마일스톤 무관)

1. 사용자 3D 결과물·개발 세션 인게임 구현 화면의 디렉션 부합 검수, 수정 지시.
2. 에셋 마스터 리스트·용량 배분의 유지 보수 (마일스톤별 실측 반영).
3. 사운드 디렉션의 입력이 되는 "확정 무드" 문서 관리 (A1 승인 후 HQ가 사운드 디렉션 작성 — 개발 계획서 6장).

## 리스크 메모

| 리스크 | 대응 |
|---|---|
| SD 캐릭터 확정 지연 → AD-2 병목 | AD-2의 적·HUD·이펙트·스펙 작업을 선행하고 캐릭터만 후속 편입 |
| 컨셉(2D)→ 로우폴리 3D 번역 실패 | AD-1부터 "로우폴리로 번역 가능한가"를 안 채택 기준에 포함, AD-2 시트에 폴리 예산 명시 |
| 3.0x 가독성과 스타일 충돌 | 적 컨셉은 실루엣 흑백 테스트(축소·1프레임)를 통과해야 채택 |
| 용량 예산 초과 | 마스터 리스트에 에셋별 예산 상한 명기, 매 마일스톤 실측 대조 |
