## A. 픽셀 아트 사양 ★

픽셀 아트는 **해상도와 색 수가 곧 아트 스타일**이다. 이걸 정하지 않으면 스프라이트 사양서를 쓸 수 없다.

**A1. ★ 캐릭터 스프라이트 해상도** — 소녀 스프라이트를 몇 픽셀로 잡을까?
- (a) **32×32 내외** — 고전적, 디테일 최소, 실루엣 승부. 제작 부담 최소
- (b) **48×48 내외** — 표정·의상 디테일이 조금 들어감. 모바일 세로 화면에 무난 (AD 권고)
- (c) **64×64 이상** — 디테일 풍부, 현대 인디 픽셀 게임 다수가 이 대역. 제작 부담 큼
- (d) 잘 모르겠다 → AD가 목업으로 비교안 제시

**A2. ★ 팔레트 색 수** — 전체 게임에서 쓸 색의 총량
- (a) **16색 내외** — 강한 통일감, 레트로. 이펙트 표현 제약
- (b) **32~48색** — 통일감과 표현력의 균형 (AD 권고)
- (c) **제한 없음** — 그라데이션·글로우 자유. 픽셀 아트의 결이 약해짐

**A3. 애니메이션 프레임 감각**
- (a) **절도 있게** — 프레임 적게(2~4), 딱딱 끊기는 맛. 제작 부담 적음
- (b) **부드럽게** — 프레임 많이(6~12), 유려함. 제작 부담 큼
- (c) 상황별 혼용 (평상시 적게, 액션 순간 많이)

**A4. 아웃라인** — 캐릭터·적에 검은 테두리를 두를까?
- (a) 두른다 — 배경과 분리가 확실, 가독성 우수
- (b) 안 두른다 — 회화적, 배경과 융화
- (c) 캐릭터만 두르고 배경 오브젝트는 안 두른다

## B. 제작 파이프라인 ★★ (가장 급한 항목)

AI 생성물은 픽셀 그리드가 불균일해 **스프라이트로 직접 쓸 수 없다.** 현 컨셉아트는 전부 "방향 제시용"이다.

**B1. ★★ 실제 스프라이트를 누가 만드는가?**
- (a) 사용자가 직접 도트를 찍는다 (Aseprite 등)
- (b) 외주·에셋 스토어 구매
- (c) AI 생성 → 도트 정리 툴·수작업 보정 파이프라인을 만든다
- (d) 아직 모르겠다 — 방향 재정리 후 결정

**B2. AD의 산출물 형태** — 무엇을 받으면 가장 쓸모 있는가?
- (a) **스프라이트 시트 사양서** (해상도·프레임 수·팔레트·애니 리스트를 문서로)
- (b) **레퍼런스 이미지** (AI 생성 컨셉을 계속 뽑아 시각 기준 제공)
- (c) 둘 다

## C. 게임 화면 설계 (2D 전환으로 재정의 필요) ★

**C1. ★ 판정 영역** — 어디서 벨 수 있는가?
- (a) **소녀 주변 원형 범위** — 소녀를 따라다님. 현 목업 방식
- (b) **화면 고정 가로 밴드** — 특정 높이대를 지나는 적만 벨 수 있음
- (c) **스와이프 궤적이 닿으면 무조건** — 판정 영역 개념 자체를 없앰
- (d) AD가 시안으로 비교안 제시

**C2. 적 동선** — 정측면에서 적이 어디서 오는가?
- (a) 아래에서 위로 올라온다 (소녀가 떨어지므로 상대적으로 상승)
- (b) 좌우 가장자리에서 진입
- (c) 둘 다 혼용

**C3. 대체 셀링포인트** — 기획서 2장의 "Z축 3D 스와이프"가 무효가 됐다. 무엇으로 대체할까?
- (a) **"2D 액션 손맛 + 속도 다이얼"** — 낙하 속도가 배경 스크롤로 직관적으로 보이는 점을 전면에 (AD 제안)
- (b) **픽셀 아트 비주얼 자체**를 셀링포인트로
- (c) 다른 안이 있다

## D. 톤·레퍼런스 재확인

**D1. 2등신 SD에서도 "성인 소구 / 유아용 인상 금지"가 유효한가?**
2등신은 본질적으로 귀여움 쪽이다. 무드·팔레트·연출로 성인 톤을 유지할 수는 있으나, 1회차 때보다 난이도가 높다.
- (a) 유효하다 — 무드로 잡아라
- (b) 완화한다 — 귀여움이 전면에 나와도 괜찮다
- (c) 오히려 갭(귀여운 그림 × 어두운 내용)을 세일즈 포인트로

**D2. 픽셀 아트 레퍼런스** — 산나비 외에 떠오르는 작품이 있는가? (게임·도터·아트북 무엇이든)

**D3. 배경의 3D 사용 범위** — "배경 일부만 3D"라 하셨는데 어디까지?
- (a) 최소 — 구름 레이어 정도만, 사실상 2D처럼 보이게
- (b) 중간 — 부유 오브젝트(잔해·구조물)를 3D로, 약간의 시차 회전
- (c) 적극 — 배경 전체가 3D, 캐릭터만 2D 스프라이트

## AD 분석 — 답변에서 도출되는 사항

### 1. D2의 옥토패스 트래블러는 이 프로젝트의 구조 그 자체다

세 레퍼런스 중 **옥토패스 트래블러(HD-2D)** 가 결정적이다. 2D 도트 스프라이트 + 3D 배경 + 심도 표현이라는 구성이 본 프로젝트의 2.5D 정의(**캐릭터·몬스터·이펙트·UI = 2D 픽셀 / 배경 일부 3D**)와 정확히 일치한다. D3의 "3D는 연출 임팩트와 공간감 있는 오브젝트 배치 정도"라는 지침도 HD-2D의 운용 방식과 같다.

**→ 2.5D 구현 방식의 기준 레퍼런스로 채택한다.** 세 작품의 역할 분담:

| 작품 | 참조 대상 |
|---|---|
| **옥토패스 트래블러** | **2D 스프라이트 × 3D 배경의 결합 방식**, 심도·조명 처리, 공간감 |
| **산나비** | 액션 연출, 이펙트의 과장, 시네마틱 픽셀 연출 |
| **데이브 더 다이버** | 캐릭터의 귀여움과 게임의 밀도를 양립시키는 톤, 현대적 픽셀 마감 |

### 2. ⚠ A4(아웃라인 없음) + 어두운 팔레트 = 캐릭터가 배경에 묻힌다

세 답변이 한 지점에서 충돌한다.

- A4: 아웃라인을 두르지 않는다 → 배경과의 분리를 **명도·채도 대비에만 의존**하게 된다
- 현 캐릭터 디자인: 의상이 거의 전부 검정
- 확정 팔레트: 니어블랙·딥인디고 중심의 어두운 톤

48×48에서 이 셋이 겹치면 캐릭터가 어두운 배경에서 실루엣조차 읽히지 않는다. 아웃라인은 보통 이 문제의 안전장치인데, 그것을 뺐다.

**다만 사용자의 E1 답변("너무 블랙 톤으로 통일하고 싶지 않다")이 이미 같은 방향을 가리킨다.** 두 답변은 충돌이 아니라 같은 요구의 두 표현으로 읽힌다.

**→ 대응:** 아웃라인 대신 **(a) 캐릭터에 확실한 액센트 컬러 면적 확보 (b) 캐릭터 주변 림라이트/글로우 (c) 배경의 명도를 캐릭터보다 확실히 낮거나 높게 유지** 세 축으로 가독성을 확보한다. E1 시안에서 이를 검증한다.

### 3. C3(대체 셀링포인트)는 AD 소관에서 제외

`DECISIONS.md` 5장의 미결 1번을 **HQ·기획 전담**으로 재분류한다. AD는 의견(“2D 액션 손맛 + 속도 다이얼”)만 남기고 결정에서 빠진다.

### 4. B1은 파이프라인이 확정됐으나 규격 확인이 남았다

AI 생성 → 픽셀 그리드 정리 스킬 경로가 확정됐다. 다만 AD가 만들 레퍼런스 이미지의 사양(원본 해상도, 색 수, 배경 투명 여부 등)은 그 스킬이 무엇을 입력으로 받느냐에 종속된다. 스킬 접근이 가능해지면 규격을 맞춘다.
