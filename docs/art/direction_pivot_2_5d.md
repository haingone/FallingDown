# 방향 전환 검토 — 3D 툰 셰이딩 → 2.5D 픽셀 아트

## 1. 전환 사유 (사용자)

> "3D 캐릭터 애니메이션과 카메라 조정, 그리고 플레이의 융합이 쉽지 않을 것 같고, 밸런스를 맞추다가 게임의 재미를 놓쳐버릴 것 같다."

**AD 소견: 근거 있는 우려로 판단한다.** 개발 계획서 8장은 이미 "glTF 스킨 애니메이션 파이프라인(Blender/Tripo → three.js)"을 리스크로 등재했고, 본 세션의 아트 탐색 5라운드가 전부 **카메라·자세·크롭 문제**로 반려·재작업된 것 자체가 그 난이도의 실증이다. 3D 캐릭터를 화면에서 성립시키는 데 아트 리소스가 과도하게 소모되었고, 그 시간은 재미 검증에 쓰이지 못했다.

## 2. 새 방향 정의

**2.5D — 게임플레이 요소는 2D 픽셀 아트, 배경 일부만 3D.**

| 레이어 | 형식 | 내용 |
|---|---|---|
| 캐릭터 (소녀) | **2D 픽셀 아트, 2등신** | 낙하·베기·도약·피격 스프라이트 |
| 몬스터 (A/B계열, 보스) | **2D 픽셀 아트** | 거리 단계별 스프라이트 |
| 까마귀 | **2D 픽셀 아트** | 6종 수집 요소 |
| 이펙트·UI | **2D 픽셀 아트** | 참격, 폭발, HUD, 판정 링 |
| 배경 | **3D 일부 + 2D** | 구름 터널·부유 오브젝트 소수를 3D로, 약간의 카메라 무빙 |

## 3. 이 전환이 해소하는 것

| 기존 리스크 | 해소 여부 |
|---|---|
| glTF 스킨 애니메이션 파이프라인 (계획서 8장) | **소멸** — 스프라이트 시트로 대체 |
| 3D 캐릭터 카메라·자세 성립 문제 (본 세션 5라운드) | **소멸** — 스프라이트는 항상 정면을 보므로 카메라 종속성 없음 |
| 캐릭터 폴리·텍스처 용량 (메시 20MB) | **대폭 절감** — 스프라이트 시트는 KB 단위 |
| 모바일 WebGL 성능 (드로우콜·라이팅) | **개선** — 스프라이트 배칭, 라이팅 불요 |
| 사용자 3D 제작 리드타임 (Blender/Tripo) | **소멸** — 3D 실작업이 배경 오브젝트 소수로 축소 |

## 4. 새로 생기는 문제 (반드시 선결)

### 4.1 ~~픽셀 아트 × Z축 원근~~ — **철회 (2026-08-26)**

> AD가 카메라를 오해해 제기했던 쟁점. 사용자 정정으로 **소멸**했다.
>
> **정정: 이번 방향은 Z축(깊이) 낙하가 아니라, 정측면 카메라에서 Y축(화면 세로)으로 떨어지는 구도다.**
>
> 깊이 방향 확대가 없으므로 스프라이트를 스케일할 일이 없고, 픽셀 퍼펙트가 자동으로 유지된다. LOD·정수배 스케일 논의는 불필요하다.

### 4.2 ⚠ 인터뷰 1회차 결정과의 충돌

인터뷰에서 확정했던 캐릭터 방향이 무효화된다.

| 인터뷰 확정 사항 | 2등신 픽셀에서의 상태 |
|---|---|
| "캐릭터 비율 **5~6등신 이상**" | **폐기** — 2등신으로 전환 |
| "소녀 = **멋진 스타일** 담당" | **재정의 필요** — 2등신 SD는 귀여움 축 |
| "귀여움·캐주얼은 **까마귀가 담당**" | **역할 분담 붕괴** — 소녀도 귀여움 축으로 이동 |
| "캐주얼하되 **성인 소구**" | 유지 가능 — 픽셀 아트는 성인 인디 게임 관객에 강함 |
| "AI 웜/황변 톤 금지, 디즈니·픽사 금지" | 유지 |
| "스테이지별 팔레트, 스타일리시·화려" | 유지 — 픽셀에서도 성립 |

**결정 완료 (2026-08-26): 1번 채택.**

> **캐릭터는 SD 체형으로 귀엽게, 액션을 멋지게 표현한다.** (사용자 제시 레퍼런스: 산나비)

- 소녀의 매력 = **귀여운 몸 + 멋진 액션**. 두 축을 한 캐릭터가 동시에 담당한다.
- 멋짐의 전달 매체는 캐릭터 조형이 아니라 **모션·이펙트·연출**이다 — 참격 궤적, 잔상, 히트스톱, 화면 연출, 극적인 림라이트.
- 까마귀와의 역할 분담 재정의: **소녀 = 액션 / 까마귀 = 마스코트·수집**. 소녀가 귀여움 축으로 이동해도 까마귀는 "더 둥글고 작고 무해한" 조형으로 차별화한다.
- 인터뷰의 "성인 소구, 유아용 인상 금지"는 유지 — 시네마틱 연출과 어두운 무드가 이를 담보한다.

### 4.3 기타

- **까마귀와의 차별화:** 소녀도 2등신이면 까마귀와 실루엣이 유사해질 수 있다. 까마귀는 더 둥글고 작게, 소녀는 코트·우산의 각진 실루엣으로 구분.
- **적 실루엣 1프레임 식별(기획서 17.3)**은 픽셀 아트에서 오히려 유리하다 — 저해상도가 실루엣 단순화를 강제한다.
- **3D 배경과 2D 스프라이트의 접합:** 픽셀 스프라이트와 매끄러운 3D 배경이 섞이면 이질감이 생길 수 있다. 배경도 디더링·포스터라이즈 후처리로 픽셀 톤에 맞추는 셰이더가 필요할 수 있다 — 이펙트 예산에 반영.

## 7. 카메라 규격 정정 (2026-08-26) — **정측면 / Y축 낙하**

> 사용자 정정: **"이번 아트 방향성은 z축으로 떨어지는 게 아니라, 그냥 정측면 카메라 뷰에서 y축으로 떨어지는 상황을 그리는 거다."**

AD가 이전 3D 방향의 Z축 구도를 그대로 끌고 와 오해했다. 본 절이 정본이다.

### 확정 카메라

| 항목 | 내용 |
|---|---|
| 시점 | **정측면 (side view)** — 평면 직교에 가까운 옆모습 |
| 낙하축 | **Y축 (화면 세로)** — 소녀는 화면 아래로 떨어진다 |
| 소녀 위치 | 화면 상단~중단의 고정 위치, 좌우로 약간 이동 |
| 배경 | 세로로 위쪽으로 흐름(패럴랙스 다층). 3D 오브젝트가 섞여 약간의 카메라 무빙 |
| 원근 | **없음** — 소실점·단축·깊이 스케일 전부 불사용 |

### 이 정정이 바꾸는 것

**해소되는 문제**
- 픽셀 × 깊이 스케일 충돌 (4.1) — 소멸
- 3D 카메라 상태 머신, FOV 조정, 판정 링 디스크 투영 — 전부 불요
- 본 세션 5라운드를 태운 "캐릭터 자세·크롭·카메라" 문제군 — 근본 소멸

**새로 정의해야 하는 것**
1. **판정 영역:** 기존 "소녀 주변 판정 링(Z 깊이면)"이 성립하지 않는다. 정측면에서는 **소녀 주위의 원형 판정 범위** 또는 **화면 가로 밴드**가 후보. 스와이프가 2D 화면 좌표에서 직접 판정되므로 구현은 훨씬 단순하다.
2. **적 동선:** 기존 "원경 소실점에서 Z축으로 접근"이 성립하지 않는다. 정측면에서는 **화면 아래에서 위로 올라오거나, 좌우 가장자리에서 진입**한다. 기획서 10.0(통과형/체류형) 정의를 2D 동선으로 재작성해야 한다.
3. **속도 표현:** FOV 확장 대신 **배경 스크롤 속도 + 세로 속도선 + 모션블러 + 화면 흔들림**으로.

### ⚠ 기획서 개정 — 프로덕트 정의 변경 수준

| 기획서 | 현행 | 상태 |
|---|---|---|
| 2장 셀링포인트 2 | **"Z축 3D 스와이프"** — 적이 소실점에서 카메라를 향해 날아오고 판정 링에서만 벨 수 있다 | **셀링포인트 자체가 무효.** 대체 셀링포인트 정의 필요 |
| 4장 | 3D 3인칭 추적 카메라, Z축 적 동선, FOV 60→72° | **전면 개정** — 정측면 2D + Y축 낙하 |
| 10.0 | 통과형: 원경→링 통과→카메라 뒤 프레임 아웃 | 2D 동선으로 재정의 |
| 15장 | 소녀 주변 판정 링 | 2D 판정 영역으로 재정의 |
| 17.1 | "판정 링 깊이 인지" 검증 항목 | **삭제** — 깊이가 없어 검증 대상이 아님 |

**AD 소견:** 셀링포인트 2번(Z축 스와이프)이 사라지는 것은 가볍지 않다. 다만 기획서 2장의 진짜 코어는 **셀링포인트 1번(낙하 속도 = 셀프 난이도 다이얼)** 이고, 이것은 정측면 Y축에서도 100% 성립한다 — 오히려 낙하 속도가 배경 스크롤 속도로 직관적으로 보인다. 대체 셀링포인트로는 **"2D 액션의 손맛 + 속도 다이얼"** 축이 자연스럽다. HQ 판단 요망.

### AD 자체 검수

**성립한 것**

1. **"귀여운 몸 + 멋진 액션"이 실제로 성립한다.** PX4가 결정적 — SD 캐릭터가 작고 귀여운데도 대호 참격·잔상 체인·산화하는 적으로 화면이 충분히 멋있다. 결정 사항 1번이 그림으로 검증됐다.
2. **정측면 Y축 구도가 즉시 읽힌다.** PX3에서 세로 패럴랙스와 아래에서 올라오는 적만으로 "떨어지는 중"이 성립한다. 앞선 3D 방향에서 5라운드를 태운 문제가 1회에 해결됐다.
3. **소녀와 까마귀의 실루엣이 구분된다** — 각진 코트·우산 vs 둥근 덩어리.
4. **적 실루엣이 저해상도에서 오히려 선명하다** — 기획서 17.3(1프레임 식별) 요건에 유리하다는 예측이 맞았다.

**미달·과제**

| # | 문제 | 대응 |

| 1 | **등신이 2등신이 아니라 3등신에 가깝다** | 2등신을 고수할지, 3등신을 채택할지 결정 필요. 현 결과물의 가독성은 3등신이 더 좋다 |

| 5 | 깃털 HP 칸수·정렬은 여전히 부정확 | UI 킷 벡터 스펙으로 분리 (기존 결정 유지) |

### AD 자체 검수

**3등신이 명확히 나은 점**

1. **캐릭터 가독성** — T1에서 얼굴·코트·스커트·부츠가 전부 읽힌다. 2등신에서는 덩어리로만 보이던 것이 디자인으로 읽힌다.
2. **픽셀 그리드가 훨씬 균일하다** — 도트에 가까운 결과물. 실제 스프라이트 제작의 참고 기준으로는 이쪽이 유용하다.
3. **UI 표현력** — T5에 보스 체력바까지 자연스럽게 들어갔고, T4의 위기 연출(적색 경고 글로우 + HP 1 + 붉은 비네트)이 명확하다.

**2등신이 나았던 점**

4. **낙하감·속도감** — PX3/PX4의 세로 패럴랙스와 흐름이 더 강했다. T1·T3은 캐릭터가 크고 배경이 정적이라 "떨어지는 중"보다 **"서 있는"** 느낌이 난다.

**⚠ 비교의 한계 (반드시 감안할 것)**

이 A/B는 **순수한 등신 비교가 아니다.** 2등신은 Seedream, 3등신은 nano_banana_pro로 생성되어 **모델 차이가 섞여 있다.** 위 1~4의 차이 중 어디까지가 등신 때문이고 어디까지가 모델 때문인지 분리되지 않았다. 최종 판단 전에 **같은 모델로 등신만 바꾼 대조군**을 한 번 더 뽑는 것이 정확하다.

### ⚠ 발견된 심각한 문제 — 캐릭터 디자인 드리프트

**5장 안에서 캐릭터가 서로 다른 인물로 나온다.**

| 컷 | 머리 | 의상 | 확정안 준수 |
|---|---|---|---|
| T1 | 검은 긴 머리 | 검은 코트 + 주름 스커트 | ○ |
| T2 | **파란 머리** | **흰 옷** | ✕ |
| T3 | 검은 머리 | 검은 코트 | ○ |
| T4 | **갈색 머리 + 후드** | **갈색 벨트 복장** | ✕ (거의 다른 캐릭터) |
| T5 | **갈색 머리** | **파란 옷** | ✕ |

원인은 **캐릭터 레퍼런스 없이 텍스트 프롬프트만으로 매 컷을 독립 생성**하기 때문이다. 모델을 바꾸면서 더 심해졌다.

**결론: 캐릭터 시트 확정이 목업보다 선행되어야 한다.** 확정 시트를 레퍼런스 이미지로 물려야 컷 간 동일 인물이 유지된다. 이 순서를 지키지 않으면 목업을 몇 장을 더 뽑아도 같은 문제가 반복된다.

### AD 권고

1. **등신: 3등신 채택 권장.** 캐릭터 가독성 이득이 크고, 낙하감 약화는 배경 처리(세로 스트리크 강화, 석조 아치 제거)로 해결 가능한 별개 문제다.
2. **단, 확정 전에 같은 모델로 2등신/3등신 대조군을 한 번 더** 뽑아 모델 변수를 제거한다.
3. **다음 작업은 목업이 아니라 캐릭터 시트 확정**이다. 그 뒤에야 목업이 일관성을 갖는다.
4. T1·T3의 배경 석조 아치는 하늘 낙하 설정과 맞지 않으므로 제거한다.

### ⚠ 이전 검수 판단 정정

9장에서 "**2등신이 낙하감 우위**"라고 기록했으나, **모델 변수를 제거하고 다시 보니 이 판단은 성립하지 않는다.**

당시 3등신은 nano_banana_pro로 생성되어 배경에 정적인 석조 아치가 들어갔고, 그 때문에 낙하감이 약해 보였다. 같은 Seedream으로 다시 뽑은 S1은 **다리를 뻗은 낙하 자세와 세로 흐름이 오히려 2등신보다 강하다.** 낙하감 차이는 등신이 아니라 배경 처리에서 온 것이었다.

**정정된 결론: 3등신이 캐릭터 가독성과 낙하감 양쪽에서 2등신보다 낫다.**

### 검수 결과

**해결된 것**

1. **캐릭터 드리프트 완전 해소.** 5장 전부 검은 긴 머리 + 검은 하이칼라 코트 + 주름 스커트 + 검은 레깅스·부츠로 일관된다. 프롬프트에 의상·머리색을 금지 조항까지 포함해 명시한 것이 유효했다. (다만 이는 **임시 방편**이며, 캐릭터 시트를 레퍼런스로 물리는 것이 정식 해법이라는 판단은 유지된다.)
2. **석조 아치·실내 구조 제거** — 하늘 낙하 설정과 맞는 배경으로 교정됐다.
3. **3등신 실루엣이 액션을 지지한다** — S1의 뻗은 다리, S2의 돌진 자세, S4의 방어 자세가 전부 읽힌다. 2등신에서는 불가능했던 자세 표현이다.
4. **S5 보스**가 강하다 — 거대 실루엣, 단일 발광 안구, 탄막 예고선, 보스 체력바까지 성립.
5. **S4 위기 연출** — 적색 경고 글로우 + HP 1칸 + 어두운 팔레트로 위기가 즉시 읽힌다.

**남은 과제**

| # | 문제 | 대응 |
|---|---|---|
| 1 | 픽셀 그리드가 여전히 완전히 균일하지 않다 (Seedream의 회화적 성향) | 방향 제시용이라는 전제는 유지. 실제 스프라이트는 도트 작업 필요 — **제작 주체 결정 대기** |
| 2 | 2.5D의 3D 레이어가 여전히 시각적으로 분리되지 않는다 | 3D 오브젝트 사용 범위 별도 검증 |
| 3 | 판정 영역이 캐릭터 중심 원으로 그려짐 | 캐릭터 중심 / 화면 중심 고정 중 확정 필요 |
| 4 | 깃털 HP 칸수·정렬 부정확 | UI 킷 벡터 스펙으로 분리 (기존 결정 유지) |

## 11. 확정 — 캐릭터 비율 2등신

> **사용자 결정 (2026-08-26): 2등신으로 확정.**
> AD 권고는 3등신이었으나 사용자 결정에 따라 **2등신을 프로젝트 기준으로 확정한다.** 이후 모든 캐릭터·목업·에셋은 2등신을 전제로 제작한다.

### 확정 사양

| 항목 | 값 |
|---|---|
| 비율 | **2등신** — 머리가 전체 키의 약 1/2 |
| 체형 | SD 치비, 짧고 뭉툭한 팔다리, 큰 눈 |
| 매력 축 | **몸은 귀엽게, 액션은 멋지게** (11장 이전 결정 유지) |
| 기준 시안 | `art/explore/pixel_2_5d/` PX1·PX3·PX4 계열 |

### 2등신 확정에 따른 후속 조치

1. **`pixel_3head_sd/`·`pixel_3head/` 는 참고 자료로 강등.** 3등신 계열 시안은 채택하지 않는다.
2. **액션 표현이 2등신의 최대 과제.** 3등신에서 성립했던 자세 표현(뻗은 다리, 돌진 실루엣, 방어 자세)이 2등신에서는 팔다리 길이 제약으로 약해진다. 따라서 **멋짐의 부담이 이펙트·모션 트레일·화면 연출로 더 크게 이동한다.** PX4가 그 성립 증거이며, 이 방향을 강화한다.
3. **낙하감은 배경 처리로 확보한다** — 세로 패럴랙스 속도, 속도선 밀도, 화면 흔들림. 캐릭터 자세에 의존하지 않는다.
4. **캐릭터 시트를 2등신 기준으로 확정**하고, 이후 모든 목업 생성 시 레퍼런스로 물린다.
