## 2. 남은 게이트 절반 — 실기기 검증 (사용자 협조 필요)

계획서 M1 게이트 중 헤드리스로 불가한 항목: FPS(Unity 전환 트리거 확정), 오분류 체감, WebAudio 지연, FOV 72° 멀미, 3.0x 반응 가능성, 손맛.

**절차:** 로컬에서 `claude/m1-graybox` 체크아웃 → `cd game && npm ci && npm run dev -- --host` → 폰으로 LAN URL 접속 (같은 Wi-Fi). 튜닝 패널(기본 표시, `?debug=0`로 숨김)에서 FPS·1% low·오디오 지연을 읽고, 90초 시퀀스를 몇 판 플레이하면 된다.

## 3. 개발 세션 질문에 대한 HQ 권장안

### 질문 1 (핵심 — 사용자 결정 필요): 게이지 배율 곱

3.0x 플레이 시 게이지가 18.8초(W2)에 차서 "클라이맥스에서 도약"(기획서 11.3) 의도와 충돌.

**HQ 권장: (b) 게이지 충전만 배율 미적용 (하급 1기 = 고정 5%).**
- 근거: 깃털은 "판 안의 리듬 자원"(기획서 14장)이고, 텐션 커브(11.3)는 킬 수 기준으로 설계되어 있다. 배율 곱은 메타 성장 자원(비늘)과 점수에만 걸어도 "빠르게 떨어질 용기 = 성장 속도" 고리는 유지된다.
- (a) 곱 유지+요구량 상향은 저속 플레이어가 클라이맥스까지 게이지 100%에 못 미치는 역효과 (11.3의 "자연 도달" 설계 붕괴).
- (c) 현행 유지는 판당 도약 2~3회로 "매 판의 감정 정점 1회" 훼손 + 도약 순환은 까마귀 "검은깃"의 빌드 정체성인데 속도만으로 공짜 획득.
- 채택 시 기획서 개정 필요: 8장 게이지 행과 14장 깃털 행의 "배율 적용" 문구 삭제.
